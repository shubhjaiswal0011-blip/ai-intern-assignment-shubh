# AI Internship Assignment

A practical internship submission demonstrating frontend form handling and workflow automation with n8n.

## Highlights

- **Student Lead Capture Form:** a responsive HTML, CSS, and JavaScript form that collects student details and sends them to a webhook.
- **Conditional lead routing:** an n8n workflow that routes PG/PhD submissions to Gmail and UG submissions to Google Sheets.
- **Scheduled weather workflow:** an n8n workflow that fetches and formats current weather and forecast data from the Open-Meteo API.

## Repository structure

```text
part-a/  Student Lead Capture Form
part-b/  n8n workflow exports and workflow screenshots
part-c/  Assignment documentation and screen recording
```

## Technology

HTML · CSS · JavaScript · n8n · Webhooks · Gmail · Google Sheets · Open-Meteo API

## Notes

The n8n workflows are provided as JSON exports. Configure your own credentials and webhook settings before running them.
